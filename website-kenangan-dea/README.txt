WEBSITE KENANGAN — DEA DAFIZTA

MENJALANKAN
1. Ekstrak ZIP ini.
2. Buka index.html dengan klik dua kali untuk melihat website di browser.

MENGEDIT KENANGAN DAN SURAT
Buka index.html dengan VS Code atau Notepad. Cari judul "Potongan cerita kita" dan ubah teks contoh menjadi kenangan kalian sendiri. Ubah pula isi surat dan caption foto agar terasa lebih personal.

MENGGANTI FOTO PERMANEN
Simpan tiga foto yang boleh dibagikan ke assets/photos dengan nama foto-1.jpg, foto-2.jpg, foto-3.jpg. Di index.html, ubah masing-masing sumber assets/photos/foto-1.svg menjadi assets/photos/foto-1.jpg (dan seterusnya). Foto yang dipilih lewat klik galeri hanya pratinjau lokal, bukan unggahan ke website.

MUSIK
Tombol Musik menyalakan melodi sederhana yang dibuat langsung di browser. Pengunjung perlu menekan tombol agar browser mengizinkan audio.

PUBLIKASI GRATIS DENGAN GITHUB PAGES
1. Buat akun di https://github.com.
2. Buat repository Public bernama dea-kenangan.
3. Unggah index.html dan folder assets ke root repository.
4. Masuk Settings > Pages.
5. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
6. Setelah aktif, GitHub akan menampilkan link website, biasanya https://USERNAME.github.io/dea-kenangan/

Privasi: website statis ini tidak mengumpulkan data, tetapi jika publik siapa pun yang memiliki link dapat melihat kontennya. Jangan masukkan informasi atau foto yang tidak ingin dibagikan.
